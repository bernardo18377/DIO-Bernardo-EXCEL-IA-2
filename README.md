1-como usar

Abra o arquivo, substitua os dados de exemplo e preencha as informações de cada aba, Dá para navegar pelos botões do menu lateral ou pelas abas na parte de baixo

2-mudanças
Mantive a estrutura das aulas e fiz algumas mudanças no visual: cores em roxo e lilás, textos mais curtos, nomes das abas em minúsculas e uma imagem de leão nas três telas, com o mesmo tamanho e posição.
